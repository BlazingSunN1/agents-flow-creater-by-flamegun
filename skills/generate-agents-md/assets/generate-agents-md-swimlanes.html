代码审查发现

审查结果：只读独立 Agent 持续执行需求稳定性与黑盒审查；发现已测试先行修复，当前 411 项回归和 265 个关键源码变异全部通过。

已修复：--allow-pattern 只豁免基础设施误报，不再跳过敏感信息、占位符和待办扫描。

已修复：开发计划、模块日志、泳道图和前端验证均在指定章节内校验完整规则；反引号敏感值和同一行独立身份主机也不会被漏检。

已修复：敏感信息扫描已覆盖常见标记与大小写变体；非法 mode/scope 不能绕过根/子作用域门禁。

已修复：模块切换会关闭其他模块，返回系统总览会收起所有模块，避免多个模块同时展开。

本轮新增：每次代码模块修改后仍自动审查真实变更和受影响调用链；泳道改为阶段任务完成时统一同步，阶段中仅在流程变化时立即更新并验证，减少无效重画与 Token 消耗。

本轮修复：全局规则不得反转机器门禁；需求基线路径、版本和哈希进入证据缓存键；追踪链拒绝跨语义角色复用同一工件；模板模式深检嵌套 schema；implementation 阶段的前端改动同样必须提供点击与 E2E 证据。

本轮加固：所选需求的 Code module 必须覆盖当前 Changed files；模块日志只记录自身需求编号；跨角色复制同内容工件、重复授权字段、旧证据预复用及模板中的失败/可选门禁均失败关闭。

相邻缺陷修复：追踪工件内容身份消除尾随空白差异；execution run 模板明确只填模块所属 REQ；仅 user-visible 的非前端任务不再误触浏览器/E2E。

边界修复：追踪内容身份消除零宽格式字符但保留正文内部空白语义；命令清单可正确声明 trace=internal 的真实前端重构，仍强制浏览器与 E2E。

浏览器可用性修复：本地 HTML 和前端页面必须先由回环地址上的已登记服务提供 HTTP(S) 入口；证据头与点击转录精确绑定实际 URL，拒绝 file://、含敏感连接值和非 HTTP(S) 地址。

页面身份加固：HTTP(S) URL 还必须映射预览根目录下的当前入口工件，并在证据头和点击转录中同时绑定入口文件与浏览器实际响应体 SHA-256；泳道浏览器必须使用回环地址并只能以当前系统总览为入口，无关网页或模块细图不能冒充。

复用稳定性加固：缓存键新增风险/扩展理由、直接依赖边界和 Build ID；工作集父级或叶子符号链接失败关闭；复用必须绑定结构化成功 run、唯一模块、Build ID、验收环境、当前缓存键和逐项证据哈希；单一源 run 只服务单模块，多模块必须重跑。

阶段与追踪修复：implementation 阶段允许 BLACK_BOX 以严格的未启动状态留空 run 和工件，completion 仍要求完整独立黑盒；同一追踪单元格的多个 REQ 链接会被聚合门禁全部识别。

行为证据加固：DOM 快照必须与实时入口响应字节相同且为 UTF-8；动作保存浏览器计算的可见/启用状态并按声明顺序及次数执行，每次点击绑定前后 DOM 工件并证明断言节点自身变化且结果可见；DOM/CSS/ARIA/禁用状态、组合器和项目相对外链 CSS 按文档顺序、优先级与 !important 交叉校验，无法重放的 CSS import 阻断；截断 HTTP、目录入口、无调色板索引 PNG、未知关键块、不连续 IDAT、隐藏或非交互泳道跳转全部失败关闭。风险字段固定为三段，复用源 run 的模块、基线、代码、Build ID、验收环境、风险、需求、规范化文件/编号集合及严格历史上下文路径/哈希逐项绑定当前上下文，多证据统一使用无歧义逗号语法。

Token 优化：入口 Skill 已去除重复细节；每次执行先建立最小工作集，组合代码、命令、配置、环境和输入指纹生成缓存键，只有验证器确认完全一致且证据存在时才复用。

本轮路由优化：普通事实提取不再加载受控敏感配置细节；相关能力只在用户本次明确授权时读取独立策略。外部多模型、证据复用和浏览器验收也拆为按场景加载的独立契约，历史上下文复用模板已加入显式资源路由。

本轮审查修复：Machine-Enforced Policy 现在解析完整 YAML 标量并拒绝未知覆盖键；前端与泳道 CSS 的 :not() 支持多个排除参数、状态伪类且只按顶层逗号拆分，未知状态按失败关闭处理，隐藏控件不能伪造点击闭环。通用清单只路由复用与浏览器契约，不再复制底层 schema。

稳定性优化：完整 argv 必须匹配来源声明；共享记录通过固定目录描述符、文件锁、期望哈希与原子替换防 symlink 竞态；前端证据拒绝空文件、伪报告和越界链接。

多 Agent：实现 Agent 是代码和共享记录的唯一写者；实现阶段不提前要求黑盒；小型、标准、高风险严格启用最少必要角色；每个独立输入只覆盖当前需求的角色所需工件并逐文件绑定 SHA-256，独立输出再绑定输入清单 SHA-256，额外/缺失/漂移输入、证据复用或开放分歧都阻断。

外部模型并列通道：显式启用时由隔离的 spawn_external_agent.py 让 Kimi 负责完整设计与修订、DeepSeek V4 外部子 Agent 通过官方 Chat Completions 编写黑盒用例并审查，Codex GPT 独立裁决；同候选门禁绑定脱敏上下文、固定提示词、Thinking Max + JSON Output 请求配置、请求/返回模型、finish_reason=stop、外部原始响应/usage、规范化合同及原生 GPT 输入/检查/输出证据。最多 6 轮，耗尽仍未双审通过则机器标记 incomplete。DeepSeek 用例仍须由独立黑盒通道真实执行，外部顾问不改变 Codex 模型与环境、不写工作区，也不替代原生子 Agent、唯一写者和运行时门禁。

失败关闭：根级 AGENTS 使用权威机器策略枚举；交付包总门禁绑定 AGENTS、追踪矩阵、工作集、真实命令、计划进度、自动审查、当前模块 run、完成态 latest/index、多 Agent 与适用前端证据；追踪表坏行不再静默丢弃。

本轮修复：计划绑定需求基线，进度绑定实现 run/code 和模块记录链接；自动审查用结构化 JSON 绑定真实命令、argv、时间、退出码和 rerun，模块 run/latest 绑定实际审查、独立评审、泳道与前端证据，严格拒绝 symlink 父链、hardlink 别名、隐藏字段和开放工作。

结构优化：AGENTS 策略、追踪解析和原生 E2E 报告已拆分为独立校验模块，入口文件与函数均受大小边界约束。

一键自检：python3 scripts/validate_skill.py 聚合 Skill 包、代码结构、全部 CLI smoke、全量回归、源码变异和泳道脚本语法 6 层检查，任一层失败即整体失败。

明确例外：经用户授权的项目级敏感连接配置仅按需进入独立规则与专用校验；用户明确要求时可只读审查该策略及隔离效果，但不获得写入或传播真实值的权限。默认上下文不展示策略细节，公共模板始终脱敏。
